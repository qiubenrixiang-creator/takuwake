# 卓分けの館

ボードゲーム会の席決めを、診断クイズで行うツールです。
参加者がスマホで質問に答えると、遊びたいゲームの傾向が近い人同士が同じ卓に集まります。

隠しルート・図鑑・称号・エンディングを含んだ、遊べる作りになっています。

- 公開URL: https://takuwake.vercel.app/
- 制作: HINATA AKIMOTO

---

公開までの手順は `SETUP.md` にまとめてあります。
このREADMEは、中身の説明と変更の記録です。

## ファイル構成

```
takuwake/
├─ index.html              館（参加者が使う画面）
├─ kumi.html               卓組みの間（幹事用）
├─ css/
│  └─ style.css            見た目
├─ js/
│  ├─ store.js             端末内の保管庫（旧Firebase）
│  ├─ data.js              質問文・卓の設定・称号・合言葉  ← 文章はここ
│  ├─ app.js               館の動き
│  ├─ assign.js            卓の割り当ての計算
│  └─ kumi.js              卓組みの間の動き
├─ assets/
│  └─ audio/               BGM・効果音
├─ SETUP.md                公開までの手順  ← 最初に読む
└─ README.md
```

**質問文や卓の説明を直したいときは `js/data.js` だけ**を編集してください。
プログラムに触れずに中身を書き換えられます。

## 使い始めるまで

GitHub Pages に置くだけで動きます。**外部サービスの設定は要りません。**
手順は `SETUP.md` にまとめてあります。

以前はFirebaseに名簿を預けていましたが、
コンソールでの設定やルールの貼り替えが必要でうまくいかなかったため、
**4文字の合言葉**で幹事に伝える方式に変えました（2026年9月）。
通信が一切要らなくなったので、会場の電波が悪くても完全に動きます。

## 当日の流れ

1. 参加者に公開URLを教える
2. 各自が診断すると、画面に**4文字の合言葉**が出る
3. 幹事は名前の入力欄に `たくぐみ` と打ち、卓組みの間へ入る
4. **名前と合言葉**を打ち込んでいく
5. 全員そろったら「卓を組む」
6. 「発表リンクを作る」→ LINEなどに貼る
7. 参加者はリンクを開けば、以後いつでも「📜 記録」から席を確認できる

合言葉には「どの卓か・腕前・途中退出の有無・授かった称号」が入っています。
4文字目は検査用なので、打ち間違えるとその場で弾かれます。

## 今回の変更点

### Firebaseをやめ、GitHubだけで動くようにした

名簿の共有にFirebaseを使っていましたが、公開のたびにコンソールでの設定と
ルールの貼り替えが必要で、そこが失敗すると名簿への登録ごと黙って止まっていました。

診断結果を**4文字の合言葉**にして、幹事が打ち込む方式に変えました。
参加者どうしを通信でつなぐ必要がなくなり、次のようになりました。

- 外部サービスの設定が一切要らない（GitHub Pages に置くだけ）
- 通信を一切しないので、会場の電波が悪くても完全に動く
- 名前がどこかのサーバーに残らない
- 外部スクリプト2本が消えて、起動が軽くなった

**発表はリンクで行います。** 幹事が「発表リンクを作る」を押すと、割り当てが
URLの中に詰め込まれます。参加者が一度開けばその端末に残るので、以後いつでも
「📜 記録」から席の一覧を見られます。一斉に押しつけるのではなく、
見たいときに見る形です。

待機モードは、幹事が組んだ時点が発表になるため不要になりました。

### 卓組みの間にも音を入れた

館と同じ仕組みで、BGMと効果音が鳴るようになりました。
BGMは卓組みの間専用のもの（`bgm_kumi.mp3`）です。

効果音は操作ごとに鳴り分けます。

| 操作 | 音 |
|---|---|
| 扉を開ける・参加者を迎える・席を入れ替える | 決定音 |
| 合言葉の打ち間違い・名簿から外す | キャンセル音 |
| 卓を組む | ファンファーレ |
| 発表リンクを作る | アイキャッチ |
| 固定・卓数の計算・結果のコピー | 戻る音 |

右上の「🔊 音あり」で切り替えられます。選んだ状態は次回も残ります。

iPhone対策として、**画面を最初に触った瞬間**にすべての音の再生許可を取ります。
ブラウザは「ユーザーが触った瞬間」に始まった再生しか許さないためです。
そのため、ごく最初の一音だけ鳴らないことがあります。

### 継承の儀の報酬を「継承の証書」に変えた

新しい秘宝を作って館に増やす仕組みでしたが、ここまで辿り着いた証が
形として残るほうがよいと判断し、**証書**に変えました。

名前・日付・到達した卓・称号・秘宝・来訪回数が刻まれ、画像として保存できます。
下部に実績コード（`TKW1-...`）が入っていて、将来ボードゲームライブラリーと
つなぐときの手がかりになります。

秘宝が1つ失われる代償もなくしました。証書は「ここまで来た記録」なので、
記録が減る代償と噛み合わないためです。


### 直した不具合

**同じ名前の人が上書きされていた**
名簿のキーに名前を使っていたため、「ひなた」が2人いると
先に診断した人の記録が消えていました。端末ごとに発行するIDをキーに変更しました。

**リセットが失敗しても成功と表示されていた**
`db.ref('roster').remove()` の結果を見ずに「リセットしました」と出していたため、
権限エラーで消えていなくても気づけませんでした。成功・失敗を出し分けるようにしました。

**名簿への登録が失敗しても気づけなかった**
通信が切れた状態で診断を終えると、無言で登録されないままでした。
失敗時に画面上部へ通知を出します。

### 使いやすくした点

**文字送りをスキップできる**
メッセージ欄をタップすると残りが一気に表示されます。
1文字45ミリ秒なので、長いセリフは10秒近くかかっていました。
参加者が順番待ちしている場面では、ここが一番の詰まりどころだったはずです。

**幹事が人数を共有できる**
これまでは全員が同じ人数を手入力する必要があり、
ひとりでも違う数字を入れると卓数が食い違っていました。
幹事が一度共有すれば、他の端末に自動で反映されます。

**Enterキーで進める**
人数・名前・深淵の解答欄で、Enterでも決定できます。
スマホのキーボードでも決定キーが出るようにしました。

**人数入力で数字キーボードが出る**
`inputmode="numeric"` を指定しました。

**通信が切れたら画面に出る**
オフラインだと名簿が更新されませんが、これまで無表示でした。
上部に警告を出します。

**音がずれる問題を直した**

`play()` は「今すぐ鳴らせ」ではなく「鳴らす準備をせよ」という要求で、
実際に音が出るまでに時間差があります。その間に `pause()` を呼んでも
遅れて再生が始まってしまうため、場面が変わったあとに前のBGMが
鳴り出していました。再生と停止に札を付けて、止めるよう指示された後に
始まってしまった音を、その場で確実に止めるようにしました。

あわせて、音声ありを選んだ瞬間に7ファイルを同時再生していた
先読み処理をやめ、読み込みの指示だけを出すようにしています。
BGMは必要になってから取りに行きます。

音源も再圧縮しました（13MB → 3.8MB）。モノラル32kHzですが、
ループBGMなので聴感の差はほとんどありません。

**読み込みを二段階に分けました。** iOS対策として全音声に再生許可を出していましたが、
許可を出すと読み込みも始まるため、「音声あり」の一押しで数MBの通信が走り、
会場の電波では画面が固まったようになっていました。
今は効果音と主BGMだけを先に許可し、隠しルート・深淵・エンドロールのBGMは
次に画面を触った時に回しています。

**iPhoneで無音になる問題も直しました。** iOSのSafariは、ユーザーが触った
その瞬間に始まった再生しか許しません。「音声あり」を押した直後に
読み込み処理を挟んでいたため、その間に許可が切れて拒否されていました。
今は押した瞬間に全音声の許可だけを取り、それが済んでから鳴らしています。

**スタッフロールのBGMがiPhoneで鳴らない問題を直した**

`.ogg` 形式はiOSのSafariが再生できません。mp3に変換しました。

**各卓への経路数を揃えた**

通常診断の全経路がどの卓に流れるかを数えたところ、B卓が17経路ある一方で
H卓は1経路しかなく、隠し卓と同じ確率になっていました。

```
変更前  B17 C11 A10 D6 F4 G3 E2 H1
変更後  A10 C10 D10 B9 H9 G8 E7 F7
```

新しい質問を8つ足し、いくつかの行き先を差し替えています。
上位3卓で7割を占める状態だったので、実際には満卓時のフォールバックが
席決めの大半を担っていました。

**画面が固まるバグを直した**

`q_bluff_deep3` の「いいえ」が、存在しない `q_bluff_C` を指していました。
心理戦ルートの通常経路なので、実際に踏んだ人がいたはずです。
質問として書き起こして繋ぎました。

未使用だった `q_coop_deep2` と `q_coop_deep4` も経路に組み込んであります。

**会をまたいだ記録を追加した**

同じ端末で来館するたび、その日の卓を1件だけ記録します。
結果画面に「館へ来るのは、これで3度目じゃ」「まだ見ぬ卓：D卓・H卓」と出ます。

通算の称号も3つ追加しました。

- 【館の常連】3度の来訪
- 【館の古株】10度の来訪
- 【八卓行脚】8つの卓すべてに座る

日付をキーにしているので、同じ日に何度診断しても1回として数えます。
記録は端末ごとです。機種変更すると引き継がれません。

**ぬしが場を認識するようにした**

来訪回数と、その日すでに診断を終えた人数に応じて挨拶が変わります。

- 「今日はまだ誰も来ておらん。お主が一番乗りじゃな」
- 「本日はお主で7人目じゃ」
- 「どうやら、お主で最後のようじゃな。皆待っておるぞ」
- 「おお、ひなた。よう戻ってきたな。これで3度目じゃ」

**セリフを校閲した**

助詞の誤り、鉤括弧の中身が文になっていない箇所、口調の揺れなどを直しました。
名前の入力を促す場面で「人数をちゃんと入力せよ」と言っていた誤りも含みます。

**卓組みの間を追加した**

館の中の一室として、幹事用の画面を足しました。診断順に席が埋まる方式を
やめられます。あわせて、幹事が席を告げるまで結果を伏せておく
待機モードを用意しました。
あわせて、診断の直前に腕前と途中退出を聞く2問を足しました。
図鑑収集モードでは聞きません（席に関係しないため）。

**結果に卓の説明が付く**
「A卓（笑い声の宴の間）」だけでは、実際に何を遊ぶ卓なのかが伝わりません。
どんなゲームを、どんな雰囲気で遊ぶ卓かを1行で添えました。納得感が変わります。

**結果テキストをコピーできる**
全体に `user-select: none` がかかっていたため、
同卓メンバーの名前を選択できませんでした。結果欄だけ選択可にしています。

**キーボード操作でも現在位置が分かる**
フォーカス表示を追加しました。あわせて、視差やアニメーションを抑える設定を
OS側で有効にしている人には、点滅や走査線を止めるようにしています。

## 既知の課題（今後直すなら）

- `js/data.js` の `q_coop_deep2` と `q_coop_deep4` は、どこからも呼ばれない未使用の質問です。消すか、経路に組み込むか決める必要があります。
- 「次元跳躍の才」（神の座）で名簿に登録すると、その端末自身の記録を上書きします。制作者用の機能なので実害はありませんが、仕様として把握しておいてください。
- 遅刻者が後から診断した場合は、`kumi.html` で組み直しになります。すでに座っている人を「固定」してから組み直すと、必要な人だけが動きます。
- 卓ごとに遊ぶゲームを登録して、所要時間や人数と突き合わせる機能はまだありません。

## 秘宝と継承の儀（ゲーム部分）

全20点の秘宝があります。図鑑の「秘宝」の棚に並びますが、**未入手のものはヒントを出さず伏せてあります。**
入手法は口伝えで広がる想定です。

秘宝を手に入れると、画面中央に大きく現れます。名前と説明文が読め、
受け取るまで先へ進みません。同時に複数手に入った場合は、一つずつ順番に出ます。

手に入れた秘宝は図鑑でタップすると説明文が読み返せます。一度手にしてから
失った秘宝には、説明文とあわせて取り戻し方が表示されます。

### 神の座の御力（6点）

対応する秘宝を持たない御力には錠がかかります。神の座に到達しても、すぐには全部使えません。

| 御力 | 秘宝 | 入手条件 |
|---|---|---|
| 透視の才 | 万里を見透かす水晶 | 名簿を開いたまま3分間、何も操作しない |
| 次元跳躍の才 | 刻を巻き戻す羅針盤 | 一度の診断で「戻る」を10回使う |
| 真名の才 | 真名を綴る不朽の筆 | 真エンディングを見る |
| 名忘却の才 | 忘却を招く墨壺 | 名忘却の才を一度振るう（※下記の代償あり） |
| 理破りの力 | 理を断つ黒鉄の楔 | 奈落の罰15分を、逃げずに待ち切る |
| 創生と忘却の力 | 万象を還す原初の砂 | 全ルート・全称号を解放する |

**名忘却の才には代償があります。** この御力を振るうと、エンドロールから名が消えると同時に、
**振るった本人が集めた秘宝もすべて失われます。** 忘却の力は、使う者からも記憶を奪います。

実行前に確認を挟みます。図鑑には一度手にした秘宝の入手法が残るので、集め直すことはできます。
なお「忘却を招く墨壺」は、この御力を振るった者が次に神の座へ入った時に授けられます。

**創生と忘却の力**も、すべての記録とあわせて秘宝を還します。

**深淵の「代償の深淵」で失敗した場合**も同じく、到達した卓・称号・秘宝・
各種の通算カウントがすべて還ります。ただし**会をまたいだ来訪記録は残します。**
深淵の代償はゲームの中の話であり、現実に会へ通った記録まで奪うのは
筋が違うためです。

失った場合は `かいほう` で戻せます。

### 卓組みの間の鍵（1点）

**卓を統べる館主の鍵** — 三度この館を訪れると、ぬしが預けてくれます。
神の座から卓組みの間へ渡るには、この鍵が要ります。

### 継承の儀に捧げる秘宝（12点）

| 秘宝 | 入手条件 |
|---|---|
| 幾多の卓を巡りし旅の栞 | 8つの卓すべてに実際に座る |
| ぬしの落とし髭 | ぬしの顔を通算100回突く |
| 名も無き者の残り香 | 名前を空欄のまま突っぱね、N卓へ堕ちる |
| 迷わざる者の靴 | 一度も戻らず、最短の4問で終える |
| 問いを拒みし者の面 | すべての問いに「いいえ」で答え切る（H卓に着きます） |
| 反響せぬ鈴 | 音声なしで診断を終える |
| 移ろう心の栞紐 | 通算30回「戻る」を使う |
| 深淵を見る者の目 | 深淵のぬしの目を通算10回突く |
| 宵闇を告げる砂時計 | 18時〜23時のあいだに診断を終える |
| 偽りの名の写し身 | 「ぬし」と名乗る |
| 開かずの間の錆鍵 | 裏口を二度とも拒む（U卓） |
| 静寂を破らぬ枝 | 戻らず、放置もせず、5分以内に終える |

### 幻の一点

**何も持たぬ者の証** — 継承の儀で、力を受け取らずに立ち去った者だけが得ます。
**真エンディングにはこれが必要です。**

### 継承の儀

名前の入力欄に **`かたりべ`** と打つと開きます。12点から3つを捧げます（220通り）。
**三度外すと10分の封印**がかかります。

正解は「館に己を差し出した三つ」――通う足（栞）、触れる手（髭）、捨てた名（残り香）。
図鑑の古文書に《継承の理》として謎かけを載せてあります。

当てると選択を迫られます。

- **館の記憶を継ぐ** … 館に新しい秘宝を一つ遺せます。**代償として秘宝が1つランダムに失われます。**
- **何も持たずに立ち去る** … 力は得られませんが「証」が手に入ります。

儀は何度でも開けますが、証が手に入るのは最初の一度だけです。
力を継ぐたびに秘宝は1つ失われます。

代償で失った秘宝は、図鑑に入手法が表示されるので取り直せます。
**「旅の栞」だけは代償の対象外**にしてあります。取り直すのに現実の会へ何度も通う必要があるためです。

捧げる秘宝の並び順は、儀を開くたびに変わります。位置で正解を覚えられないようにするためです。

### 秘宝を遺す

力を継ぐと、館に新しい秘宝を一つ作れます。

- **名前**（20字まで）
- **いわれ**（60字まで）
- **授かる条件**を、6つの選択肢から1つ選ぶ

| 選べる条件 |
|---|
| 遺した者と同じ卓に座る |
| 館を五度訪れる |
| 深淵に足を踏み入れる |
| ぬしの顔を通算三百回突く |
| 音を絶ったまま三度診断を終える |
| 八つの卓すべてに座る |

条件を自由記述にすると達成を判定できないため、選択式にしています。

遺した秘宝は**他の全員の図鑑に並び**、条件を満たした人の手に渡ります。
図鑑には「〇〇が遺した秘宝」と作者名が刻まれ、緑色で表示されます。

**一人につき一つまで**です。二度目に儀を通ると、前に遺した秘宝を書き換える形になります。
その人が館に遺したものが一つに定まる方が重みが出ますし、図鑑が際限なく膨らむのも防げます。

遺された秘宝は、エンドロールにも「館に遺されし秘宝」として流れます。

### 幹事の合言葉

名前の入力欄に打ちます。合言葉と文言は `js/data.js` の先頭にある
`ADMIN_WORDS` にまとめてあるので、自由に書き換えられます。

| 合言葉 | はたらき |
|---|---|
| `かいほう` | 図鑑（卓・称号・秘宝）をその場で全解放。神の座へは飛びません |
| `たくぐみ` | 秘宝と鍵を解放し、卓組みの間へ渡る |
| `かたりべ` | 継承の儀を開く |

`かいほう` は**モードも進行状況も問いません。** 全消去した直後でも使えます。

これまで図鑑を全解放できるのは創造神の名・`てんくう`・コナミコマンドだけでしたが、
後者2つは図鑑収集モードでしか働かず、収集モードに入るには一度診断を終える必要が
ありました。全消去したあと復旧しづらい状態だったので、`かいほう` を用意しています。

### エンドロール

到達した卓・隠し卓・称号・秘宝・館に遺された言葉を織り込んで流れます。
所要は約55秒です。

## 音源について

`assets/audio/` の音源は、配布元の利用規約に従ってください。

このリポジトリは**公開（Public）**で運用しています。GitHub Pages の無料版が
公開リポジトリしか扱えないためです。公開にあたって、頭の隅に置いておくとよいことが
二つあります。

**一つめ。** 音源ファイルは誰でもダウンロードできる状態になります。
素材によっては「再配布禁止」と定めているものがあるので、使っている素材の規約だけは
一度確認しておいてください。もし引っかかるものがあれば、その音源を差し替えるか、
リポジトリを非公開にして Vercel から配信する形に移せます（Vercelは非公開でも配信できます）。

**二つめ。** 隠しコマンド、深淵クイズの答え、秘宝の入手条件は、すべてソースから読めます。
身内で遊ぶぶんには問題になりませんが、図鑑集めを本気で楽しんでほしい相手には
リポジトリのURLを教えないでおくのが無難です。
