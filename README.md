# たくわけの やかた（Claude版）

ボードゲーム会の席決めツールです。
参加者が質問に答えると、似た者どうしが同じ卓に集まります。

旧版（Gemini版）を土台に、中身を一から作り直しました。
見た目は**ボードゲームライブラリー（BGL）と同じ部品**で組んでいます。
色・わく・ボタン・見出し・酒場の背景・ドット絵のアイコン・上のバー・下のタブは、BGL の値をそのまま使っています。

- GitHub Pages に置くだけで動きます（外部サービスの設定は不要）
- 通信を一切しないので、会場の電波が悪くても動きます
- iPhoneで軽く動くことを最優先にしています

---

## いまできること（第1段階：席決めの芯）

**参加者**（`index.html`）

1. しんだんを はじめる
2. なまえ
3. じゅんびの2問（腕前・途中で帰るか）
4. 本編の8問
5. 結果：卓・「つよさ」・**4文字の合言葉**

**幹事**（`kumi.html`＝たくぐみの ま）

1. 参加者の「なまえ」と「合言葉」を打ちこむ
2. 1卓あたりの人数を決めて「たくを くむ」
3. 気になるところは、名前をたたいて入れ替える
4. 「はっぴょう リンクを コピー」→ LINEなどに貼る
5. 参加者がリンクを開くと、席がその端末に残り、いつでも「きょうの せきを みる」で確認できる

卓に置く札の印刷と、結果を文字でコピーする機能もあります。

**画面のつくり（BGL と同じ）**

- 上のバー：♪（BGM）・SE（効果音）・よる／ひる
- 下のタブ：しんだん／せき／ライブラリー（幹事の画面では たくぐみ）
- 席が発表されて、まだ見ていないときは「せき」タブに点がつきます

**BGL と共有する設定**

同じ `qiubenrixiang-creator.github.io` に置くと、次の3つは BGL と共通になります。
どちらで切りかえても、もう一方に反映されます。

| 設定 | 保存名 |
|---|---|
| よる／ひる | `bgl.theme2` |
| BGM | `bgl.bgmEnabled` |
| 効果音 | `bgl.seEnabled` |

「ライブラリー」タブの行き先は `js/data.js` の `SITE.libraryUrl` で変えられます（いまは `../board-game-library/`）。
卓の色も、よる用（`color`）と ひる用（`day`）の2つを `data.js` に持っています。

## 診断のしくみ（点数方式）

答えるたびに、7つの「つよさ」に点数がたまります。

| つよさ | 低い | 高い |
|---|---|---|
| おもさ | かるめ | おもめ |
| かしこさ | うんまかせ | じっくり せんりゃく |
| にぎやかさ | しずか | わいわい |
| すばやさ | ちょうこう OK | サクサク |
| かけひき | すなお | はったり |
| きずな | きそいあい | きょうりょく |
| ものがたり | ルール じゅうし | せかいかん じゅうし |

8つの卓にも、同じ7つで性格が決めてあります（`data.js` の `profile`）。
たまった点数に**いちばん近い性格の卓**へ案内します。

結果画面には「つよさ」がそのまま出るので、なぜその卓になったかが見えます。

### 行き先のかたより

全6561通りの答え方を計算し、8卓がほぼ同じ割合になるよう補正（`bias`）を入れてあります。

| | A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|---|
| 旧版（分岐ツリー） | 14% | 13% | 14% | 14% | 10% | 10% | 11% | 13% |
| 新版（点数方式） | 12.6% | 12.1% | 13.2% | 12.8% | 12.1% | 12.3% | 12.3% | 12.8% |

※旧版は「分岐の経路の数」で、新版は「全6561通りの答え方」で数えています。数え方が違うので、目安として見てください。旧版の数字は経路の偏りを直したあとのもので、直す前は1.8%〜30%でした。

それぞれの卓の「典型的な答え方」をした人は、8人とも自分の卓に着くことを確かめてあります。
一問だけ気まぐれに答えを変えても、77%はそのままの卓に着きます。

**質問や `profile` を変えると、かたよりが出ることがあります。** そのときは Claude に「かたよりを調べ直して」と頼んでください。

## 合言葉（4文字）

中身は「卓・腕前・途中で帰るか・4つのつよさ（3段階）」です。
幹事はこれを打ちこむだけで、その人の好みがわかります。

- 見間違えやすい `0` `O` `1` `I` は使いません
- 4文字目は検査用です。**1文字の打ち間違いは必ず弾きます**。隣どうしの入れ替えも9割弾きます

## 卓の割り当て

- **にぎやかさ・すばやさ・おもさ**が近い人を集めます（かしこさは違っても楽しいので見ません）
- 診断で同じ卓になった人どうしは、少し近いとみなします
- **初心者だけの卓を作りません**（説明できる人を必ず入れる）
- 途中で帰る人を、重い卓に入れません
- 組んだ卓には、その顔ぶれにいちばん似合う卓の名前が、かぶらないように付きます

計算の重みは `js/assign.js` の先頭 `ASSIGN` で変えられます。

---

## 幹事の合言葉

名前の入力欄に `たくぐみ` と打つと、たくぐみの まへ入れます。
`kumi.html` を直接開いても、同じ合言葉を求められます。
合言葉は `js/data.js` の `ADMIN_WORDS` で変えられます。

## 旧版との比べ（iPhone相当の条件で計測）

| | 旧版（最初） | 旧版（軽量化後） | 新版 |
|---|---|---|---|
| 診断にかかる時間 | 32秒 | 32秒 | 12秒 |
| そのうちボタンが押せず待つ時間 | 25.5秒 | 25.5秒 | 0秒 |
| タップ回数 | 17回 | 17回 | 12回 |
| 最初に画面が出るまで | 432ms | 170ms | 208ms |
| 結果画面で待機中のCPU | 517ms/秒 | 11ms/秒 | 2.4ms/秒 |
| 音源 | 13MB | 3.8MB | 1.1MB |

新版は文字送りの途中でも選択肢を押せます。
12秒は「セリフを最後まで表示してから押した場合」です。
新版の「最初に画面が出るまで」と「待機中のCPU」は、BGL のデザイン（酒場の背景・点滅する ▶）を入れたあとの値です。どちらも体感できる差ではありません。

## 保存について

保存先はブラウザの中（localStorage）だけです。
ボードゲームライブラリーと同じ `qiubenrixiang-creator.github.io` に置くと、保存場所を共有します。
まざらないよう、すべての名前の頭に `takuwake2.` を付けています。

これは将来、ボードゲームライブラリーとつなぐときの足がかりにもなります。

幹事の名簿は幹事の端末の中だけにあります。当日はずっと同じ端末で操作してください。
